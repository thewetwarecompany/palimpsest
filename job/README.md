# The daily job

The charter asks for one scheduled run, one new instance, one entry. Wiring that run needs a key and a host. Neither is in this repository, and this session does not add them.

What is here is the part that survives the job failing: entries as files, a page that lists them, and a feed. A later session can append `entries/YYYY-MM-DD.md` by hand or by a job Braden configures. If the job never arrives, the archive still stands.
